# 高波特率审批包（单元27）

状态：`pending_user_approval`

本文件只提交 460800 / 921600 方案与验收门槛，**不修改 MCU 默认波特率**，也不在
未批准时改写上位机默认连接参数。

批准口令建议：

```text
确认实施高波特率 <460800|921600>
```

## 1. 现状

| 项目 | 当前值 |
|---|---|
| 默认串口波特率 | 115200 |
| V1 状态轮询 | 20/50/100 Hz 可配 |
| MCU MotionTask | 20 ms，连续目标上限约 50 Hz |
| 帧缓冲 | RX/TX 128 字节 |

## 2. 候选方案

| 方案 | 波特率 | 目标 | 风险 |
|---|---:|---|---|
| A | 460800 | V2 100 Hz 状态 + 余量 | 中 |
| B | 921600 | V2 200 Hz 状态探索 | 高 |

## 3. 时钟与链路前提

实施前必须现场核对：

1. STM32G474 USART 时钟源与分频能否精确生成目标波特率。
2. USB-UART / VCP 适配器是否声明支持该波特率。
3. 线缆长度、接地、EMI 环境是否可接受。
4. DMA 与 idle-line 接收在高速率下是否稳定。
5. 上位机写队列、解析器与 Recorder 是否仍有界。

## 4. 上位机行为约束

- 默认配置保持 115200，直到审批通过并完成实测。
- 失败时一键回退 115200。
- 不允许因高波特率失败而自动重发危险动作。
- 丢样必须通过 `sample_seq`（V2）或轮询缺口检测可见。

## 5. 验收门槛

| ID | 门槛 |
|---|---|
| BAUD-001 | 连续 30 分钟只读 soak，重连后仍可 HELLO/GET_STATE |
| BAUD-002 | 误码/CRC/长度错误率低于约定阈值并写入报告 |
| BAUD-003 | 目标 Hz 的 P95 到达间隔满足设计 |
| BAUD-004 | MCU 与 PC CPU/队列长度不出现无界增长 |
| BAUD-005 | 回退 115200 后功能与数据完整性恢复 |

## 6. 明确不在本包范围

- 不默认启用 460800/921600
- 不修改 MCU 源码
- 不批准真实电机动作
- 不替代协议 V2 审批
